## Estructura del projecte
- **/backend**: Implementació del servidor en Java.
- **/frontend**: Aplicació client desenvolupada amb Flutter.

## Requisits
- Java SDK
- Flutter SDK

## Instruccions d'execució

### 1. Backend
1. Obrir la carpeta `backend` amb IntelliJ.
2. Executar la classe `Main.java`.
3. El servidor estarà disponible a `localhost:8080`.

### 2. Frontend
1. Entrar a la carpeta `frontend`: `cd frontend`
2. Instal·lar dependències: `flutter pub get`
3. Executar l'aplicació: `flutter run -d linux` o amb el dispositiu que sigui
